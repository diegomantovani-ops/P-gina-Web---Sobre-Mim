Sobre mim

Olá! Meu nome é Diego Mantovani e sou estudante de Sistemas de Informação. Tenho um forte interesse no desenvolvimento de software, criando aplicações dinâmicas e explorando a construção de interfaces de usuário.

Tenho experiência prática com linguagens como C++ e Java, desenvolvendo desde estruturas de dados complexas até aplicações desktop com Java Swing integradas a bancos de dados PostgreSQL. Também aprecio estudos sobre Interação Humano-Computador (IHC) para garantir experiências de uso funcionais e intuitivas.
